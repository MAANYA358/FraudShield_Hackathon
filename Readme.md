# FraudShield

Real-Time Financial Transaction Anomaly Detection using Machine Learning.

## Problem

Financial transaction systems need to identify suspicious transactions
quickly while minimizing false alarms.

## Solution

FraudShield uses anomaly detection to identify transactions that
deviate significantly from normal transaction patterns.

## Machine Learning

Isolation Forest

## Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Matplotlib
- Seaborn

## Dataset

Credit Card Fraud Detection Dataset.

## Features

- Transaction anomaly detection
- Anomaly score
- Suspicious transaction identification
- Real-time/simulated transaction monitoring
- Interactive dashboard
